## 规范词

从 219 条开始是规范正文，用了这几个词：

- **MUST** —— 必须做到，做不到就是不符合规范
- **MUST NOT** —— 绝对不做
- **SHOULD** —— 一般要这样，除非有明确理由
- **SHOULD NOT** —— 一般别这样，除非有明确理由
- **MAY** —— 可选

前面 1–218 条是设计和定位，里面的"必须""不能"只是强调，不算硬约束。写总纲第 9 章查缺口时，硬约束只从 219 条之后数。
